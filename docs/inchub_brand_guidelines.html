01Brand Architecture Overview
One parent. Two distinct identities.

IncHub operates two separate legal entities under one parent brand. Each entity has its own primary colour, accent, background, and tone. The parent brand — IncHub Group — is expressed only through the gold connector dot and shared credentials. All other visual elements are division-specific and must never be mixed across entities.

08Rules — Do & Don't
✓ Do
Always use cognac + gold for Corporate Services materials — website pages, engagement letters, formation proposals, family advisory documents.
✗ Don't
Never use saffron on Corporate Services materials. Saffron is exclusive to Financial Services — invoices, VAT letters, accounting reports, CRM FS tags.
✓ Do
Always use aubergine + saffron for Financial Services — the website FS landing page, VAT correspondence, CT filing cover letters, accounting dashboards, all invoices from Inchub Financial Services FZCO.
✗ Don't
Never mix the two palettes on the same document. If a proposal covers both Corporate and Financial Services, use the parent brand (gold dot, neutral background) and clearly section the two divisions.
✓ Do
Use the gold dot on the parent brand homepage and any group-level communications. The dot is the only element that unifies both entities visually.
✗ Don't
Never use the logo without the division name below it when appearing on division-specific materials. Always sub-label: "Corporate Services" or "Financial Services" in lightweight Cormorant.
✓ Do
On the CRM, tag every deal, pipeline stage, and client record with the correct division colour. This is how the team instantly knows which entity is billing and which services are in scope.
✗ Don't
Never use blue, green, or any colour outside the defined palette. The brand system is intentionally limited — its power comes from consistency across every touchpoint.
